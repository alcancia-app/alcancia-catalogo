# Seguridad del catálogo de recetas

Las recetas son **solo datos** (JSON) y Alcancía las valida antes de usarlas. Si encuentras una forma de que una receta haga algo
más que describir columnas (ejecutar código, leer archivos, colar texto que se muestre como HTML) o de que un pull request use los
permisos de los workflows, avísanos **en privado**:
[Reportar una vulnerabilidad](https://github.com/alcancia-app/alcancia/security/advisories/new) (en el repo de Alcancía, que
cubre también este catálogo). No abras un issue público y nunca mandes una cartola real.

Plazos, alcance y cómo nos cuidamos: [`SECURITY.md` de Alcancía](https://github.com/alcancia-app/alcancia/blob/main/SECURITY.md).

**English:** recipes are data-only JSON validated by Alcancía. Report security issues privately via
[Report a vulnerability](https://github.com/alcancia-app/alcancia/security/advisories/new) on the main repo (it covers this catalog
too); never open a public issue or send real bank statements. Full policy: [Alcancía's `SECURITY.md`](https://github.com/alcancia-app/alcancia/blob/main/SECURITY.md).
